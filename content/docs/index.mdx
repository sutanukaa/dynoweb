Open Overview first, continue to Get Started for setup, move into Dashboard for analytics, use DynoAgent for guided analysis and action planning, use MCP to plug Claude, Cursor, or ChatGPT into your store, use Heatmaps for page-level investigation, move into Suggestions to review and apply prioritized improvements, use SmartNudge to create behavior-triggered interventions that reach visitors at the right moment, use CRO Report for a full store audit with prioritized recommendations and exportable PDF reports, use Referrers to understand which traffic sources drive conversions and revenue, use Journeys to understand path flow and drop-off across the storefront, use Conversions to connect those storefront interactions to orders and revenue, use Cart Overview to understand product intent and pre-checkout momentum, and use Replays to inspect real shopper sessions behind those patterns.
